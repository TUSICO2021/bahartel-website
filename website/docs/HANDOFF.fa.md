# راهنمای تحویل و ادامه پروژه بهارتل

تاریخ ثبت: ۲۰۲۶/۱۱/۰۲

## محل اصلی کار

مخزن: https://github.com/TUSICO2021/bahartel-website

شاخه انتشار و سورس معتبر: `import-website-source`

پوشه پروژه: `website/`

شاخه `main` یک نسخه قدیمی‌تر از کار این گفتگو را هم دارد؛ برای ادامه طراحی و انتشار از شاخه بالا استفاده کنید. شاخه‌های دیگر را بدون بررسی جایگزین آن نکنید.

## اجرای پروژه

Node.js نسخه ۲۲٫۱۲ یا جدیدتر لازم است؛ نسخه ۲۴ آزمایش شده است.

```sh
git clone --branch import-website-source https://github.com/TUSICO2021/bahartel-website.git
cd bahartel-website/website
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

فایل `package-lock.json` را حفظ کنید. هیچ رمز، توکن یا فایل env برای اجرای سایت لازم نیست.

## انتشار Cloudflare Pages

- پروژه: `bahartel-website`
- شاخه Production: `import-website-source`
- Root directory: `website`
- Build command: `npm run build`
- Build output directory: `dist`
- نشانی اصلی پروژه: https://bahartel-website.pages.dev

پس از push به همین شاخه، وضعیت چک **Cloudflare Pages** را در گیت‌هاب ببینید. آخرین تغییر برنامه قبل از این راهنما کامیت `9af9729` است و انتشار موفق آن در https://b0a9ceb9.bahartel-website.pages.dev تأیید شد.

یک فرایند جداگانه Workers Builds نیز روی حساب فعال است که شکست می‌خورد؛ موفقیت Pages را جدا بررسی کنید. تنظیمات حساب Cloudflare در مخزن ذخیره نمی‌شود و از روی راهنمای بالا قابل بازسازی است.

## نقشه فایل‌ها

- `src/main.jsx`: ترتیب صفحات، اطلاعات پروژه‌ها، حرکت بین صفحات و رفتار اسکرول
- `src/fujitsu-copy.json`: متن کامل تأییدشده پروژه فوجیتسو
- `src/brand-visibility.css`: لوگوهای پررنگ و طراحی سبز تیره پروژه فوجیتسو
- `src/CloudNetworkPage.jsx` و `src/cloud-network.css`: اکوسیستم همراه اول و ورود تدریجی کارت‌ها
- `src/ClientsPage.jsx` و `src/data/clients.js`: صفحه مشتریان و جست‌وجو
- `src/mobile-scroll.css` و `src/responsive.css`: رفتار موبایل و اسکرول
- `public/assets/`: تصاویر و لوگوها
- `public/assets/projects/fujitsu-supplied.png`: عکس انتخاب‌شده کاربر برای پروژه فوجیتسو
- `docs/reference-materials/fujitsu-project-original.docx`: سند اصلی ارسالی کاربر
- `docs/`: منابع نام‌ها و لوگوها و توضیحات طراحی

## خواسته‌های تثبیت‌شده کاربر

۱. متن کامل پروژه فوجیتسو حفظ شود؛ خلاصه‌سازی و بازنویسی نشود. فقط نمایش اعداد آن با درخواست بعدی کاربر فارسی شده است.
۲. طراحی پروژه فوجیتسو با سایر پروژه‌ها و تم سبز تیره هماهنگ باشد. اعداد در کارت، لوگو مشخص و متن خوانا باشد.
۳. عبارت ارزش ۱۸٫۵ میلیون دلار از **عنوان** پروژه Cisco و Fortinet حذف شده است؛ مقدار شاخص پروژه حذف نشده است.
۴. لوگوهای برندها واضح‌تر و رنگی باشند؛ لوگوی ساختگی اضافه نشود.
۵. عنوان صفحه همراه اول «اکوسیستم همراه اول» است. نام‌ها بدون خط اتصال، فلش یا شکل واقعی ابر نمایش داده شوند. این صفحه نمودار مالکیت حقوقی نیست.
۶. کارت‌ها و لوگوهای موجود به‌تدریج وارد شوند؛ ترجیح reduced-motion رعایت شود.
۷. «ارتباط با ما» آخرین صفحه باشد.
۸. اسکرول روی بخش بلند باید همان بخش را حرکت دهد، حتی در ابتدا و انتهای آن نباید ناخواسته صفحه کاتالوگ عوض شود.
۹. نسخه موبایل و تبلت خوانا، بدون هم‌پوشانی یا اسکرول افقی باشد.

## نکات محتوا که هنوز نیاز به تأیید دارند

- متن پروژه Fujitsu مدل RX2540 را می‌گوید، اما روی عکس ارسالی RX2450 M2 دیده می‌شود. کاربر صریحاً خواسته فعلاً از همان عکس فایل استفاده شود؛ عکس نمای داخل یا مشخصات نسل حدس زده نشود.
- آمار کلی تعداد سرورها نیازمند تطبیق با جمع پروژه‌هاست؛ بدون تأیید کاربر اعداد تجاری تغییر نکنند.
- نام‌های افزوده اکوسیستم از گزارش تاریخی گروه استخراج شده‌اند و الزاماً مالکیت فعلی را ثابت نمی‌کنند؛ منابع در `docs/ecosystem-sources.md` هستند.

## بررسی‌های انجام‌شده

- ساخت موفق با npm ci و npm run build
- حفظ هر ۱۳ بخش متن پروژه در نمایش بازطراحی‌شده
- بررسی عدم هم‌پوشانی و اسکرول افقی صفحه اکوسیستم در اندازه‌های ۱۴۴۰×۱۰۰۰، ۱۰۲۴×۷۶۸، ۱۰۲۴×۶۰۰، ۷۶۸×۱۰۲۴، ۳۹۰×۸۴۴ و ۳۲۰×۷۴۰
- بررسی wheel واقعی روی جزئیات پروژه و فهرست مشتریان و حفظ صفحه در مرزهای اسکرول

## پشتیبان و ادامه در چت جدید

کل سورس از گزینه Code → Download ZIP روی شاخه اصلی کار قابل دانلود است. فایل ZIP خروجی در ریشه این شاخه نیز برای انتشار دستی به‌روز شده است. برای نسخه ثابت از تگ `backup-2026-11-02` استفاده کنید.

متن زیر را در چت جدید بفرستید:

«پروژه بهارتل را از مخزن TUSICO2021/bahartel-website، شاخه import-website-source، پوشه website ادامه بده. قبل از هر تغییری website/docs/HANDOFF.fa.md را بخوان. انتشار با Cloudflare Pages روی همین شاخه است. متن تأییدشده فوجیتسو را بازنویسی نکن.»

این راهنما تصمیم‌های فنی و محتوایی را حفظ می‌کند؛ خود تاریخچه کامل چت داخل گیت‌هاب نیست. برای نگهداری متن کامل گفتگو، خروجی داده‌های ChatGPT را جدا ذخیره کنید.
